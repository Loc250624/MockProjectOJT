# React starter

Đây là component tham khảo, không phải patch bắt buộc.

## Trước khi dùng

- Thay logo chữ `EL` bằng logo/component branding hiện có.
- Map các route thật vào `href`.
- Nếu dự án dùng React Router/Next.js, thay thẻ `a` nội bộ bằng router link.
- Đổi import path theo cấu trúc repository.
- Map CSS variables sang design tokens thật.
- Xóa các social platform không phù hợp.
- Chỉ thêm URL mạng xã hội khi có URL thật.
