BỘ CÔNG CỤ BẢO TRÌ & KIỂM THỬ ANL/SYS CHO CODEX

Phạm vi:
- ANL-01: Thống kê doanh thu cá nhân của giảng viên
- ANL-02: Dashboard tổng quan toàn hệ thống
- ANL-03: Thống kê học viên mới và học viên hoạt động
- ANL-04: Báo cáo doanh thu theo ngày/tháng/năm
- SYS-01: Cấu hình thông số hệ thống chung

Cách dùng nhanh:
1. Giải nén thư mục này vào thư mục gốc dự án Spring Boot.
2. Đọc README_VI.md.
3. Mở Codex tại thư mục gốc repository.
4. Gửi nội dung trong 01_MASTER_PROMPT.md.
5. Yêu cầu Codex thực hiện theo từng giai đoạn: DISCOVERY -> TEST -> FIX -> REGRESSION -> REPORT.
6. Không cho phép Codex tự ý xóa dữ liệu, đổi kiến trúc hoặc sửa ngoài phạm vi khi chưa có bằng chứng.

Khuyến nghị:
- Tạo branch riêng trước khi chạy:
  git checkout develop
  git pull
  git checkout -b fix/anl-sys-maintenance
- Sao lưu database test.
- Không chạy file SQL trên production.
