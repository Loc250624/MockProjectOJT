# Regression Prompt

Sau khi sửa ANL-01..04 và SYS-01:

1. Chạy toàn bộ test hiện có.
2. Chạy test mới.
3. Kiểm tra login/logout và OAuth route không bị ảnh hưởng.
4. Kiểm tra Student dashboard/course learning không bị ảnh hưởng.
5. Kiểm tra Teacher dashboard/course management không bị ảnh hưởng.
6. Kiểm tra Admin user/course/blog/payment pages không bị ảnh hưởng.
7. Kiểm tra enrollment/payment status vẫn đúng.
8. Kiểm tra mọi navigation link liên quan.
9. Kiểm tra console và server log.
10. Tạo regression report theo template.
Không tuyên bố hoàn thành nếu test chưa chạy; phải ghi rõ test nào không thể chạy và lý do.
