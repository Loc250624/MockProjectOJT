# Prompt ANL-02

Kiểm tra và sửa Admin Overview Dashboard.

Bắt buộc:
1. Inventory tất cả widget.
2. Xác định service/repository cung cấp từng KPI.
3. Loại dữ liệu hard-code/mock khỏi production flow.
4. Bảo đảm card/link điều hướng đúng.
5. Bảo đảm widget rỗng không làm sập trang.
6. Chuẩn hóa format number/currency/date.
7. Sửa layout responsive theo design system hiện có.
8. Test chỉ Admin truy cập.
9. Test dashboard khi DB rỗng và có dữ liệu.
10. Ghi rõ định nghĩa từng KPI.
